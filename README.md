# DimensionNode — Indie Game Developer Portfolio

A personal portfolio website for an indie game developer, built with pure HTML, CSS, and JavaScript.

## Live Site

Hosted on GitHub Pages: `https://<username>.github.io`

## Features

- 🎮 **Game Showcase** — Card-based layout with Steam & Epic Games Store links
- 🌙 **Dark Mode** — Gaming-friendly dark theme
- 📱 **Responsive** — Mobile, tablet, and desktop support
- ⚡ **No Dependencies** — Pure vanilla HTML/CSS/JS, no frameworks

## Project Structure

```
├── index.html          # Main single-page site
├── css/
│   └── style.css       # Styles (dark theme, responsive)
├── js/
│   └── main.js         # Interactions (scroll, menu, animations)
├── images/             # Game screenshots & assets
└── docs/
    └── github-pages-guide.md
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Edit placeholder content with your own info

## Deployment

Push to your `<username>.github.io` repository's `main` branch. GitHub Pages will automatically deploy your site.
